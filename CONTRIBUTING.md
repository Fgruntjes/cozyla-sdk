# Contributing

- Tracker: GitHub issues on `fgruntjes/cozyla-sdk`. PRs target `main`.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/).
- One Cozyla domain (to-dos, chores, rewards, meals, notes, ...) per PR: client methods, API routes, tests and the matching section in `docs/cozyla-cloud-api.md`.
- Never commit decompiled vendor code, APKs, tokens or personal data. Test fixtures are hand-written.
- AI-generated contributions open with: `🤖 This was written with AI assistance (Claude Code) and reviewed by a human.`
